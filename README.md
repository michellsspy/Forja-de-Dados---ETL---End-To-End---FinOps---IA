
# Forja de Dados — ETL End to End | FinOps | IA

Laboratório de Engenharia de Dados de ponta a ponta, baseado na arquitetura Forja de Dados v1.3.

## Objetivo

Implementar uma plataforma de dados utilizando Databricks, Lakeflow, Delta Lake e Unity Catalog, com foco em:

- Ingestão e processamento incremental
- Arquitetura Medalhão
- Qualidade e governança de dados
- Portões de validação e quarentenas
- Reprocessamento e rastreabilidade
- Observabilidade e FinOps
- Automação de pipelines e CI/CD
- Engenharia de Dados e Inteligência Artificial

## Tecnologias

- Databricks
- Lakeflow Connect
- Lakeflow Spark Declarative Pipelines
- Lakeflow Jobs
- Unity Catalog
- Delta Lake
- Neon PostgreSQL
- Python e SQL
- GitHub Actions
- Databricks Declarative Automation Bundles

## Ambientes

DEV, HML e PRD, com isolamento lógico por catálogos.

## Fonte inicial

Neon PostgreSQL — domínio hoteleiro.

## Arquitetura

Forja de Dados v1.3 — Planos de Controle, Dados, Governança e Observabilidade.
